# Приглашение на юбилей Ирины

Статический сайт для GitHub Pages. Код приглашения: `irina1976`. Чтобы открыть список гостей, трижды нажмите `3 октября` и введите PIN `1976`.

Список хранится в файле `gusses` как JSON. Сайт читает его из `https://raw.githubusercontent.com/ivansmirnov20151-afk/fuppy/`.

Настройка защищённой отправки ответов описана в [SETUP.md](SETUP.md). Токен GitHub не должен появляться в публичных файлах сайта.
